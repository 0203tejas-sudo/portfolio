# Tejas L. Portfolio

A responsive personal portfolio website for Tejas L., a Computer and Communication Engineering student focused on AI/ML and Computer Vision.

## Files
- `index.html` – portfolio content
- `style.css` – responsive design
- `script.js` – mobile navigation and year
- `assets/resume.pdf` – place your final resume PDF here

## Before publishing
1. Replace `https://github.com/` links with your actual GitHub profile/project repositories.
2. Put your final resume PDF at `assets/resume.pdf`.
3. If you want a profile photo, replace the TL circle in `index.html` with an image.
4. Review your project descriptions and add screenshots/demo links.

## Publish on GitHub Pages
1. Create a GitHub repository named `portfolio`.
2. Upload all files in this folder.
3. Open the repository's Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to deploy.
6. Your site will normally be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`
